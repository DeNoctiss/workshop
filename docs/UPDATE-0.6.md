# Мастерская 0.6 — выделение, покраска и закупки

Дата поставки: 3 ноября 2026 года.

## Установка и сохранение существующих данных

В архиве находится папка `workshop`: исходники, тесты, инструкции и готовая сборка `dist`. Сначала скачайте резервную копию **своей базы** через настройки установленной мастерской. Архив приложения не содержит личную базу.

Для разработки: в папке `workshop` выполните `npm ci`, затем `npm run dev`. Для размещения на статическом хостинге используйте содержимое `dist` либо соберите его командой `npm run build`. Открытие HTML через `file://` не поддерживается.

При обновлении на прежнем адресе, в том же браузере данные IndexedDB сохраняются. При смене домена или порта перенесите базу через ZIP. Старые проекты, материалы, документы покраски и снимки производств поддерживаются. Общая схема базы остаётся 3; новые документы покраски имеют внутреннюю версию 2. Поле закупок необязательное: оно появляется при первом использовании.

## Выделить и перекрасить деталь

1. Откройте проект → «Доска» → «Перекраска». Выберите фото проекта или загрузите JPG/PNG/WebP. Оригинал остаётся неизменным; рабочая копия ограничена 2048 px по длинной стороне.
2. Палочкой нажмите на нужную деталь. Сначала появляется **выделение**, фотография ещё не меняет цвет. Допуск ΔE регулирует сходство с исходным цветом клика. По умолчанию выбирается только смежная область с четырьмя соседями.
3. Если нужна вся группа похожих участков, отключите «Только смежная область». Флажок «8 соседей» разрешает диагональные соединения. Прозрачный фон исключается из цветового поиска. Анализируется оригинал, а не нанесённые краски.
4. Исправьте выделение: «Добавить», «Вычесть» или «Пересечь», свободное/полигональное лассо, кисти `+` и `−`. Мягкие края у всех инструментов используют одинаковые правила.
5. В меню «Выделение» доступны инверсия, снятие и «Обработать край». Расширение/сужение ±20 px, растушёвка 0–20 px. Результат пересчитывается от маски до текущей операции: возвращение ползунка не накапливает размытие. Примените или отмените обработку.
6. Нажмите «Слой из выделения». Пустое выделение не закрашивает всё фото. Для рисования с нуля создайте «Пустой слой для кисти».
7. В «Цветах» укажите HEX или выберите материал из каталога. Если HEX отсутствует, редактор сообщает об этом; серый вместо него не подставляется. Ссылка и снимок выбранного цвета сохраняются у слоя. Смена цвета каталога позже не меняет старый вариант.
8. В «Слоях» меняйте непрозрачность, режим, порядок и видимость. Чтобы поправить границы готовой детали, нажмите **«Редактировать область»**, исправьте временную маску и выберите **«Применить область»** или **«Отмена области»**. До применения маска слоя не меняется.
9. Дождитесь статуса «Сохранено». «Готово» завершает запись и возвращает на доску. Если выделение ещё не применено, при закрытии появится уточнение. PNG экспортирует только результат окраски, без контура, курсора и служебной подсветки.

Палочка сравнивает цвет, а не узнаёт одежду, волосы или кожу. Для серой фигурки на сером фоне полезно сначала ограничить деталь лассо, затем пересечь с результатом палочки и довести кистью.

## Режимы цвета

| Режим | Результат |
| --- | --- |
| Обычный | При полном покрытии и 100% — выбранный HEX на непрозрачном пикселе. Тени перекрываются. |
| Цвет | Сохраняет светлоту исходника, поэтому итоговый RGB может отличаться от образца. |
| Умножение | Затемняет и тонирует, подходит для теней. |
| Мягкий свет | Мягкое тонирование с зависимостью от основы. |

При 0% слой не вносит вклад ни в одном режиме. Исходная прозрачность сохраняется; покраска не расширяет силуэт. Подсветка «Контур / Маска / Без подсветки» относится к временному выделению и не влияет на экспорт. Для проверки цвета отключите её или примените выделение к слою.

**Сила кисти**, **жёсткость кисти**, **непрозрачность слоя** и **подсветка** — разные параметры. Сила кисти записывается в маску мазка; частота событий мыши не делает один мазок плотнее. Отдельные повторные мазки могут усиливать покрытие. Кисть и ластик слоя работают только с активным слоем и ограничиваются текущим выделением, если оно есть.

## Управление

| Действие | Клавиши / способ |
| --- | --- |
| Палочка | W |
| Свободное лассо | L |
| Переключить вид лассо | Shift+L |
| Кисть слоя / ластик | B / E |
| Добавить / вычесть / пересечь | Shift / Alt (Option) / Shift+Alt при работе инструментом; либо кнопки |
| Размер кисти | `[` / `]`, числовое поле или ползунок; 1–200 рабочих px |
| Перемещение | Удерживать Space и тянуть изображение |
| Зум под курсором | Ctrl/Cmd + колесо |
| Масштаб 100% | Кнопка с текущим процентом |
| Вписать | Кнопка с рамкой |
| Полигон | Клики — вершины; Enter, двойной клик или первая вершина — завершить; Backspace — удалить вершину |
| Снять выделение | Ctrl/Cmd+D |
| Отмена / повтор | Ctrl/Cmd+Z / Ctrl/Cmd+Shift+Z; Ctrl/Cmd+Y также поддерживается |
| Прервать операцию | Esc; сначала закрывается открытое меню или отменяется текущая операция |
| Сравнить с исходником | Удерживать «Оригинал» |

В текстовых полях буквенные команды и отмена редактора не перехватываются. Масштаб — отношение CSS-пикселей к рабочим пикселям, а не увеличение исходного файла. На малом экране правую панель можно свернуть. История доступна в текущем сеансе: до 30 действий, ориентир 64 МБ уникальных масок; текущий документ и ближайшее действие могут требовать больше. Между открытиями сохраняются слои, но не история и не временное выделение.

## Что докупить

В «Материалах» появилась кнопка «Что докупить», в боковом меню — «Закупки».

1. Откройте «Источники расчёта». Выберите пополнение материалов на пороге/ниже, активные производства и будущие партии.
2. Для будущего проекта укажите количество изделий и один общий либо отдельные запуски. Это влияет на расход «на запуск». Если у проекта уже есть активная партия, ещё одна не учитывается без флажка «Дополнительная партия».
3. «Оставить целевой запас» добавляет пополнение после выбранных работ. Начальная цель — одна упаковка, но не меньше порога. В строке «Расчёт и правки» можно задать свою цель; после изменения нажмите «Пересчитать».
4. Сформируйте список. Для каждого материала показаны чистая нехватка, покупаемый объём, упаковки, известная стоимость и причина. Материалы соединяются по ID, а не по названию или цвету. Неизвестная цена обозначается отдельно.
5. В раскрываемой строке можно изменить количество, объём упаковки и заметку. Количество не может быть меньше рассчитанной нехватки. Ручной объём сохраняется; если новая нехватка его превысила, объём снова округляется по упаковкам.
6. Добавьте ручные позиции при необходимости. Связь с материалом склада позволит затем оформить приход; свободная позиция остаётся строкой чек-листа. Ручные позиции не меняются от пересчёта рецептов.
7. Галочка **«Куплено»** запоминает купленный объём, **не меняя склад**. Если потребность выросла, строка снова станет неотмеченной и объяснит причину.
8. **«Оприходовать»** — отдельная форма фактического количества и необязательной общей стоимости. Подтверждение атомарно создаёт один приход и связывает его со строкой. Повторное оприходование этой строки запрещено. Для остатка частичной покупки пересчитайте список или добавьте отдельную позицию.
9. Используйте «Текст», CSV или «Печать / PDF». PDF сохраняется через диалог печати браузера. Приходы остаются в раскрываемой истории списка, но не включаются в текущую выгрузку.

### Формула

`A = S − R` — доступно, с сохранением отрицательных значений. `D` — дополнительная потребность, ещё не включённая в действующие резервы. `T` — целевой запас при включённом пополнении.

`Q = max(0, D + T − A)`; при упаковке `P` покупаемый объём по умолчанию `ceil(Q / P) × P`.

Пример: склад 500 г, резерв 200 г, новая потребность 400 г, цель 100 г. Доступно 300 г, нехватка 200 г. При упаковке 1000 г предлагается 1 упаковка. Уже зарезервированные 200 г повторно в `D` не входят. Пополнение ровно до текущего порога может дать Q=0: это предупреждение, а не покупка.

Стоимость подтверждённого прихода обновляет текущую цену материала пропорционально объёму его упаковки; снимки старых производств сохраняют прежние цены. Площадь окрашенной детали на картинке не переводится в миллилитры и не создаёт расход.
