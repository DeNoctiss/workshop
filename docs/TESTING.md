# Проверки 0.5.0

Проверено 29 октября 2026 года. Использовались отдельные демонстрационные данные, а не пользовательская база.

## Автоматические проверки

`npm test`: **97 тестов в 5 файлах, все успешно**.

- 30 доменных: стоимость, смеси, резерв, завершение, отмена, брак, исторические цены и запрет повторного списания.
- 16 регрессионных: пороги запасов, общие/отдельные партии и атомарность серии запусков.
- 11 хранения: ZIP с Blob, транзакции IndexedDB, конкуренция, сохранение этапа и настройки цвета.
- 20 инфраструктурных: миграция v1 → v3 в настоящей Dexie, старый ZIP, каталог, задачи, координаты доски, конфликты, копирование проекта, защита изображений и восстановление.
- 20 новых (`update05.test.ts`): раздельные области и прозрачность при flood fill; допуск оттенков; непрерывная кисть; ластик; растушёвка; привязка/отсоединение групп без скачка; совместное движение; направления/удаление связей; независимость копии окраски; сохранение резерва при сверке; атомарный отказ при изменённом остатке; частичная/полная инвентаризация; неверные количества; заметка только с фото; запрет чужого вложения с откатом; ZIP и копия проекта со слоями; миграция v2 → v3.

`npm run build`: TypeScript и Vite production build успешно. Некритичные предупреждения: React Flow содержит директиву `use client`, которую Vite игнорирует; основной JS больше 500 kB до gzip. Доска и редактор с Worker загружаются отдельными файлами.

## Проверки интерфейса Chrome

В ходе разработки проверены:

- Квадраты цветов 30 × 30 px, отдельная колонка, иконки категорий; выравнивание формы материала.
- Каталог и окно выбора: стартовая вкладка «Мой склад», пагинация ниже списка.
- Компактные карточки проектов, пагинация вне сетки.
- Нижняя пагинация таблицы находится вне области прокрутки строк, включая горизонтальную прокрутку. При ручной проверке найден и исправлен подсчёт пробельных JSX-узлов как элементов списка.
- Ввод 620 и 10,5 в инвентаризации, модальное подтверждение, успешное применение, сохранение прежнего резерва 80 г / 1,65 мл.
- Создание группы отдельной кнопкой, перенос карточки внутрь, перемещение группы: оба заголовка смещаются одинаково.
- Соединение карточек, выбор двух стрелок и удаление связи без удаления карточек.
- Загрузка фотографии в заметку, миниатюра и открытие оригинала. Вставка PNG через буфер обмена. Ошибка декодирования отображается внутри формы.
- Выбор исходника в перекраске, заливка связанной области, HEX-цвет, сохранение теней, второй независимый слой, масштаб, отмена/повтор.
- Сохранение варианта на доске, перезагрузка страницы, повторное открытие с двумя слоями и сохранёнными цветами/масками.

Финальная таблица проверена в настольном окне Chrome около 1363 × 936 CSS px. Каталог 0.5 также визуально проверен в iframe шириной 390 и 768 px: подписи и фильтры переносятся без наложения. Это проверка CSS-раскладки, не реального телефона. Светлая/тёмная тема ранее проверялась в 0.4; длительная работа нового редактора в мобильных браузерах не проверена.

## Границы проверки

Не заявляются проверенными: реальные Safari/iOS/Android, физическое переполнение квоты, десятки больших фотографий, длительная нагрузка на 12 больших слоёв, полный браузерный цикл скачивание → импорт ZIP, публикация в GitHub пользователя. ZIP/Blob и атомарное восстановление проверены автоматически; тестовые Blob проверяют сохранность байтов, а не декодирование реального фото.

Перед обновлением сохраните резервную копию старой базы. Порядок обновления и новые сценарии описаны в `UPDATE-0.5.md`.
